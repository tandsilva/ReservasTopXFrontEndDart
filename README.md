# ReservasTopXFrontEndDart

Aplicação **Flutter/Dart** para gerenciamento de reservas, desenvolvida como parte de um sistema completo de reservas.  
Este repositório contém o **frontend mobile/web** da solução.

---

## 🚀 Funcionalidades
- Interface em Flutter para cadastro e gerenciamento de reservas.
- Integração com backend (APIs REST).
- Suporte multiplataforma: Android, iOS, Web e Desktop.
- Estrutura modular para fácil manutenção e expansão.

---

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Dart  
- **Framework:** Flutter  
- **Gerenciamento de Estado:** (ex: Provider, Riverpod ou Bloc – ajustar conforme usado)  
- **Banco de Dados/Integração:** Consumo de APIs REST (Spring Boot backend).  

---

## 📂 Estrutura do Projeto
- `lib/` → Código principal da aplicação.  
- `android/`, `ios/`, `web/`, `windows/`, `macos/`, `linux/` → Configurações específicas de cada plataforma.  
- `test/` → Testes automatizados.  
- `pubspec.yaml` → Dependências e configurações do projeto.
